## 六、未初始化的数据表说明

以下数据表当前**不设置**默认种子数据，原因如下：

| 数据表 | 原因 |
|--------|------|
| `Registration` | 报名记录需通过活动报名功能动态产生，不适合预设 |
| `Lead` | 意向客户需通过客服交互或员工录入动态产生 |
| `LeadFollowUp` | 跟进记录依附于 Lead，需业务流程产生 |
| `DailyReport` | 日报需员工口述或提交后产生 |
| `Complaint` | 投诉需学生提交后产生 |
| `StudentGrade` | 成绩需教务录入后产生 |
| `LeaveRequest` | 请假需学生申请后产生 |
| `ExamSchedule` | 考务需教务系统对接后产生 |
| `PsychologyProfile` | 心理画像需AI监测后产生 |
| `PsychologyWarning` | 心理预警需AI识别高危后触发 |
