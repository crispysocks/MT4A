# 客户研判 Skill

## 触发场景

当用户上传客户信息文件并表达研判意图时，自动加载本 Skill。

意图关键词包括：
- "帮我看看这个客户是否符合要求"
- "判断一下这个客户"
- "研判"
- "评估客户"
- 上传文件并询问"是否符合"

## 研判规则

### 新加坡国际本硕升学计划

**基本属性：**
- 年龄：14岁+（初中毕业生约14-16岁，高二在读约16-19岁，职高中专约17岁+）
- 学历：初中、高中（含中职、中技同等学历）、大专、本科
- 职高/中专/技校毕业获得的大专学历可通过6+6或9+6项目获得

**社会属性：**
- 家庭经济状况：中等及以上收入家庭，能承担约25-31万人民币学费
- 升学需求：希望通过留学提升学历，进入更好学校深造
- 就业需求：希望通过留学获得更好就业机会和薪资

**其他属性：**
- 留学意愿：对新加坡教育资源和环境有兴趣
- 政策关注度：对"一带一路"相关政策有一定关注

### 中德精英人才共建计划

**基本属性：**
- 年龄：18-35岁
- 学历：高中及以上学历

**社会属性：**
- 职业需求：就业导向（完成培训可签订正式劳动合同）、升学需求（可申请德国大学）、移民需求（工作两年后可申请永居）
- 技能需求：动手能力强、逻辑思维强、有德语学习能力
- 语言能力：有一定德语学习能力和表达能力，需在国内考取德语B1

**其他属性：**
- 留学意愿：对德国职业教育体系有了解和认可
- 政策关注度：关注德国职业教育政策、移民政策
- 学习态度：愿意参加线下封闭式实训

## Lead 表字段说明

Lead 表用于存储意向客户信息，关键字段：

| 字段 | 说明 | 必填 |
|------|------|------|
| name | 客户姓名 | 是 |
| phone | 电话 | 否 |
| email | 邮箱 | 否 |
| source | 来源渠道（如：客户上传文件） | 否 |
| status | 客户状态，默认 "new" | 是 |
| assigned_to | 负责员工ID（从当前用户上下文获取） | 是 |
| notes | 备注，包含意向产品、研判结论 | 否 |

## 研判流程

1. **解析文件内容**：从用户消息中提取【客户信息文件】部分的文本
2. **提取客户信息**：使用 LLM 从文本中提取姓名、年龄、学历、意向国家/地区、预算等信息
3. **对照规则判断**：
   - 检查是否符合新加坡国际本硕升学计划
   - 检查是否符合中德精英人才共建计划
   - 如果都不符合，说明原因
4. **信息补全**：如果判断为意向客户但信息不完整，追问用户补充
5. **入库**：用户确认后，使用 dbman 写入 leads 表

## 回答模板

### 符合新加坡计划
```
根据您上传的资料，该客户【{姓名}】符合【新加坡国际本硕升学计划】的画像要求：

匹配项：
- 年龄：{年龄} ✓
- 学历：{学历} ✓
- 意向：{意向国家/地区} ✓
- 预算：{预算}（如提供）

建议：可录入CRM作为新加坡项目意向客户。
```

### 符合中德计划
```
根据您上传的资料，该客户【{姓名}】符合【中德精英人才共建计划】的画像要求：

匹配项：
- 年龄：{年龄}（18-35岁范围内）✓
- 学历：{学历} ✓
- 需求：{需求类型} ✓
- 技能：{技能特征}（如适用）✓

建议：可录入CRM作为中德项目意向客户。
```

### 同时符合两个产品
```
根据您上传的资料，该客户【{姓名}】同时符合两个产品：

1. 新加坡国际本硕升学计划
   - 匹配项：{列出新加坡相关匹配项}

2. 中德精英人才共建计划
   - 匹配项：{列出中德相关匹配项}

请选择优先推荐的产品的编号。
```

### 不符合
```
根据您上传的资料，该客户【{姓名}】不符合公司现有产品要求，原因如下：
{列出不匹配的原因}

建议：该客户可作为潜在客户记录，后续如有新产品可再次跟进。
```

### 信息不足
```
已解析文件内容，但以下关键信息缺失，无法完成研判：

必填项：
- 姓名：？
- 年龄/学历：？

可选项：
- 意向国家/地区：？
- 预算：？
- 需求（升学/就业/移民）：？

请提供以上信息以便完成研判。
```

## 自动入库

当用户确认录入时，使用 dbman 执行：

```sql
INSERT INTO leads (name, phone, email, source, status, assigned_to, notes, created_at)
VALUES ('{姓名}', '{电话}', '{邮箱}', '客户研判-{产品名}', 'new', {当前员工ID}, '研判结论：符合{产品名}；{备注}', NOW())
```

## 错误处理

1. **文件解析失败**：提示"文件内容无法识别，请重新上传或直接描述客户信息"
2. **LLM 提取失败**：进入追问模式，询问关键字段
3. **入库失败**：提示"CRM录入失败，请稍后重试"，保留当前研判结果供用户重试
